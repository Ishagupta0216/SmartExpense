# SmartExpense

SmartExpense is a premium personal finance tracker built with React. It provides a polished dashboard, Indian Rupee formatting, analytics-style charts, and transaction management with local persistence.

## Features

- Premium fintech dashboard UI
- Responsive sidebar navigation
- Total balance, income, expense, and savings summary cards
- Monthly expense bar chart
- Income vs expense line chart
- Category-wise spending pie chart
- Budget progress card
- Recent transactions with search and category filters
- Transactions CRUD with add, edit, and delete flows
- Transaction search, category filtering, date sorting, and amount sorting
- Indian Rupee currency formatting using Indian numbering
- LocalStorage persistence
- Accessible modal, form labels, table semantics, empty states, and loading skeleton styles

## Tech Stack

- React.js
- Vite
- React Router
- Context API
- CSS Modules
- Recharts
- Framer Motion
- Lucide React

## Installation

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Deployment

SmartExpense can be deployed to any static hosting platform that supports Vite builds.

Recommended options:

- Vercel
- Netlify
- GitHub Pages
- Firebase Hosting

General deployment steps:

```bash
npm install
npm run build
```

Deploy the generated `dist/` directory.
